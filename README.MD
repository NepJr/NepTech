# NepTech
This is a core mod for my modpack of the same name.

This mod features a bunch of stuff that exists [Gregicallity Multiblocks](https://github.com/GregTechCEu/gregicality-multiblocks/), so various tidbits of its code and assets are in this project, so the credit for said code and assets go to them. I just renamed a bunch of the stuff to fit with my mod's naming scheme. (I believe I'm allowed to do this because GCYM is under MIT License? Please correct me if I'm wrong!)

Besides the GCYM code and assets and the circuit textures from the (presumably) cancelled Gregicallity Science, all the other code was written by me, some of the assets were made by stitching other GCYM and GT assets together, or was made using [This GT Casing Generator written in python (though I did edit it slightly to generate more textures for me)](https://github.com/TechLord22/gt-casing-texture-generator)

For anyone wanting to contribute, I apologize if the code is a mess. Once I get everything implemented that I want to implement (machines, recipes, items, etc. etc.) I will go and clean it up. Until then, I'm afraid you'll have to deal with it (Unless you want to clean it up for me, which would be appreciated but I have no expectations that anybody will)
