# AI Policy
Usage of Artificial Intelligence in this project is STRICTLY FORBIDDEN (mostly)!!!

If you submit a pull request containing AI generated code, I *may* accept it so long as you actually understand what the code is actually doing and not just submitting random AI slop. I know it can be a useful tool for developers but you should still have to understand what the code is doing. This specific instance is very much subject to change!

Any PR containing anything AI generate that *isn't* code will be automatically denied, and you will be banned from submitting any future PR. This is your ONLY warning!
